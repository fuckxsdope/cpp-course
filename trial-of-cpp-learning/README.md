# 📘 Моё обучение C++ (Практические работы)

Репозиторий содержит архив практических заданий по основам программирования на языке C++, выполненных во время обучения.

## 🛠️ Стек технологий
* **Язык программирования:** C++ (стандарт C++17 / C++20)
* **Среда разработки:** Microsoft Visual Studio

## 📂 Структура репозитория
Каждая папка содержит отдельную практическую работу:

* **ПЗ 1** — Базовые алгоритмы, работа с ветвлениями (`if/else`), вычисление модуля (`abs`) и квадратного корня (`sqrt`).
* **ПЗ 2** — Работа с циклами for и while
* **ПЗ 3** — Одномерные массивы и их сортировка
* **ПЗ 4** — Работа с циклами for и while
* **ПЗ 5** — «Массивы. Определение, описание, размещение в памяти, использование».
* **ПЗ 6** — «Массивы. Определение, описание, размещение в памяти, использование».

## 🚀 Как запустить проекты
1. Установите среду **Visual Studio** (с установленной рабочей нагрузкой "Разработка классических приложений на C++").
2. Скачайте этот репозиторий на компьютер.
3. Зайдите в папку нужного задания и дважды кликните по файлу решения `.slnx` (или `.sln`).
4. Нажмите **F5** для компиляции и запуска программы.
